# 装修顺序助手

> 装修顺序一次看明白 · 16 阶段施工流程 · 长治本地实情

一个 **PWA 网页应用**，帮装修小白业主看清施工顺序：做完这一步，下一步干什么。

📲 **可安装到手机桌面**，打开无地址栏，像 App 一样用；首次访问后 **断网也能查**（工地信号差时特别有用）。

## 内容

- **16 个施工阶段**：前期准备 → 物业报备+拆改 → 水电改造 → …… → 通风入住（顺序严格按真实施工链路）
- **每个阶段含**：本阶段说明 / 要做的工作 / ✅下一步施工 / 验收要点 / 注意事项 / 全屋智能安装时机 / 采购与选品 / 长治本地实情 / 避坑提醒
- **进度打卡**：勾选已完成，自动算进度、提示当前阶段和接下来该准备什么（数据存本地，不上传）

## 使用

### 电脑
浏览器直接打开 `index.html`，或访问 GitHub Pages 链接。

### 手机（推荐）
1. 手机浏览器打开线上链接（**必须 https**，file:// 本地打开测不出 PWA 能力）
2. 底部浮出安装条 → 点「安装」
   - **安卓**：直接弹原生确认框，一键装到桌面
   - **iPhone**：会弹出 3 步图文说明（分享按钮 → 添加到主屏幕 → 添加）
   - **微信里**：装不了，按提示点右上角「···」→「在浏览器打开」
3. 桌面出现「装修顺序」图标，打开即全屏，进度自动保存

## PWA 组成

| 文件 | 作用 |
|---|---|
| `manifest.webmanifest` | 应用清单：名字、图标、主题色、竖屏、standalone 启动 |
| `sw.js` | Service Worker：离线缓存（导航网络优先，静态资源缓存优先） |
| `icons/` | 192/512 常规图标 + 192/512 maskable 自适应图标 |
| `apple-touch-icon.png` | iPhone 桌面图标 |
| `favicon.png` | 浏览器标签页图标 |

> ⚠️ 改完内容后，把 `sw.js` 里的 `const VERSION = "hgjz-v1"` 递增为 `v2`，否则老用户会看到旧缓存。
