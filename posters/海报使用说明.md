## 二、怎么用（按场景）

### 场景 1｜发朋友圈 / 群
直接发 `海报_朋友圈版_1080x1620.png`，配文：

> 装修到底先干什么后干什么？我把 16 个阶段全整理出来了——
> 每步该做什么、验收看什么、什么时候买什么、坑在哪，一次讲清楚。
> 还按咱们长治的实际情况做了调整（供暖期、老房砖混、层高矮、冬天干）。
> **扫码直接看，可以装到手机桌面，工地随时翻。**
> 想要可打印版《装修顺序表》的，加我微信免费领。

### 场景 2｜给客户单发（签单后/量房后）
发海报 + 一句：

> 侯哥，这个你先存着。装修每个阶段该验收什么、什么时候买什么，上面都有。
> 扫码打开，点「安装」能放到手机桌面上，工地随时翻。

### 场景 3｜打印张贴
用 `海报_A4打印版_2480x3508.png`，普通 A4 纸打印即可（300dpi）。
- 贴**工地现场**：工人和业主都能扫
- 贴**门市/合作门店**：橱柜店、木门店、瓷砖店前台
- 印成**围裙**上的小二维码：用 `二维码_装修顺序.png`

### 场景 4｜短视频/图文
`海报_竖屏版_1080x1920.png` 可以直接当抖音/小红书的图片帖发，
或者在视频结尾当片尾卡（引导扫码/评论区）。

## 三、⚠️ 一个重要提醒

**微信里扫码打开，装不了 App**（微信内置浏览器限制）。
所以扫码后如果底部提示「点右上角 ··· → 在浏览器打开」，**让客户照做就行**，
在浏览器里打开就能正常安装。

发出去的时候**最好补一句**：
> 扫码后如果提示"在浏览器打开"，点右上角 ··· 选一下就行。

这样能大幅度减少客户卡在这一步放弃的情况。

## 五、想改文案/改尺寸

所有海报由脚本生成，改 `gen_poster.py` 顶部的常量即可：


改完重跑：
```bash
python gen_poster.py       # 重新出 3 张海报 + 二维码
python verify_qr.py        # 验证二维码还能不能扫
```

**改完一定要跑 `verify_qr.py`**，确认二维码没被放大/移位破坏。
